# עקרונות כתיבה משותפים

עקרונות אלה חלים על כתיבה ועריכה בכל דפי האתר. תקציר הדף הוא שמגדיר את המוצר, הקהל, צורת הפנייה והגבולות הייחודיים לו; אין להסיק אותם מהמסמך הגלובלי.

- כתבו בעברית טבעית, ברורה ומדויקת.
- העדיפו משפטים קצרים עד בינוניים ופסקאות קצרות.
- ארגנו מידע לפי צורכי הקוראים, והסבירו רעיון לפני פירוט משני.
- כתבו באופן אמין ומדוד. אל תוסיפו עובדות, מחירים, עדויות או הבטחות שלא אומתו.
- הימנעו מלחץ מלאכותי, הפחדה והאשמה.
- שמרו על עקביות במונחים ובצורת הפנייה בתוך כל דף.
- כפתור או קישור פעולה צריכים לתאר בבירור את הצעד הבא.

כשעורכים דף, קראו את `docs/landing-pages/<slug>/brief.md` כדי להבין כיצד ליישם את העקרונות האלה עבור המוצר והקהל המסוימים.
