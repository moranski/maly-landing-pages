# רשומות החלטה

רשומת החלטה שומרת את ההקשר, האפשרויות והשיקול שהובילו לשינוי. המצב הפעיל עצמו נשמר ב־`docs/products/`, ב־`docs/audiences/` או ב־`docs/design-systems/`.

## כללים

- יוצרים רשומה רק להחלטה שיש לה השפעה מתמשכת או שקשה להבין אותה מהתוצאה בלבד.
- משתמשים במספר עולה בן ארבע ספרות בתוך התחום ובשם קצר: `0002-short-name.md`.
- הסטטוסים המותרים הם `מוצעת`, `התקבלה`, `הוחלפה` ו־`נדחתה`.
- רשומה שהתקבלה חייבת לציין איזה מקור אמת עודכן.
- לא עורכים בדיעבד את הנימוק של החלטה שהתקבלה. שינוי מהותי מתועד ברשומה חדשה שמחליפה אותה.
- משימות, תוכניות יישום, פרוטוקולים וטיוטות אינם רשומות החלטה.

קובץ הבסיס נמצא ב־`docs/templates/decision.md`.
