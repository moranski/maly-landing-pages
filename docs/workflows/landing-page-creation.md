# תהליך יצירה ועדכון של דף נחיתה

## גבולות אחריות

| החלטה או נתון | מקור אמת |
| --- | --- |
| מודל תוכן והגדרות אתר | EmDash CMS |
| נוסח, הצעה ומדיה המוצגים בדף | רשומת EmDash באוסף `landing_pages` |
| הנחות מוצר וקהל, עקרונות תוכן וכוונת עיצוב | `docs/landing-pages/<slug>/brief.md` |
| עקרונות כתיבה משותפים | `docs/writing-style.md` |
| עיצוב חזותי מאושר | המקור החיצוני המקושר בתקציר הדף |
| קוד תצוגה, רכיבים, routing ואינטגרציות | ה־repo |
| הגדרות Worker, bindings וסודות | `wrangler.json` ו־Cloudflare secrets |
| נימוק היסטורי להחלטות | `docs/landing-pages/<slug>/decisions/` |

## יצירת דף

1. קראו את `.agents/skills/emdash-cms-management/SKILL.md`, את `docs/writing-style.md` ואת תבנית התקציר.
2. צרו תקציר יחיד ב־`docs/landing-pages/<slug>/brief.md` לפי הסדר: הנחות מוצר וקהל, עקרונות נגזרים, וכוונת עיצוב. אל תיצרו מסמכים נפרדים למוצר, לקהל ולעיצוב.
3. לפני בניית תוכן, בדקו דרך EmDash MCP את הסכמה החיה ואת רשומת ה־CMS הרלוונטית. אל תמציאו מחיר, הוכחה, הבטחה או יעד מסחרי שחסרים במקורות המאושרים.
4. צרו את רשומת `landing_pages` כטיוטה, בשימוש רק ב־block types ובשדות הקיימים ונתמכים ב־`src/components/landing/EmDashLandingPage.astro`.
5. העלו מדיה דרך EmDash, בדקו תיאור חלופי, שמרו טיוטה וקראו אותה בחזרה. בדקו RTL, מובייל, נגישות ויעדי קישור.
6. פרסמו רק כשהמשתמש ביקש במפורש שהשינוי יהיה חי. לאחר פרסום, בדקו את הכתובת הציבורית.

## עדכון דף קיים

1. סווגו את השינוי: תקציר, תוכן, מודל CMS, renderer או תצורת פריסה.
2. לעדכון ההקשר, ערכו את התקציר היחיד של הדף ושמרו את הסדר: הנחות, עקרונות, עיצוב. עדכנו החלטה היסטורית חדשה כשנדרש תיעוד של נימוק משמעותי.
3. לעדכון תוכן, קראו דרך MCP את הסכמה, הרשומה, הטיוטה והגרסה החיה; ערכו רק את השדות הנדרשים, שמרו טיוטה ובדקו preview.
4. לשינוי סכמה או renderer, תכננו את השינוי מול מודל EmDash והקוד ב־repo; בדקו שהשדות והבלוקים שה־renderer צורך תואמים לסכמה.
5. פרסמו רק בעקבות בקשה מפורשת לפרסום.

## בדיקות מסירה

- `npm run docs:check` עובר; הוא בודק את מפת הדפים המקומית בלבד.
- `npm run check` עובר עבור תיעוד ה־repo, build, TypeScript ו־Cloudflare dry run.
- EmDash מאשר את הסכמה והטיוטה; הסוכן קורא את השינוי בחזרה ומשווה לגרסה החיה.
- EmDash preview והעמוד הציבורי לאחר פרסום מפורש נבדקו ב־RTL, מובייל, מקלדת, נגישות וקישורים.
- לא מוצגים placeholders, מחירים לא מאושרים, עדויות ללא רשות או הבטחות תוצאה לא מבוססות.
