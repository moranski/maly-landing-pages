# תהליך יצירת דף נחיתה

מסמך זה מתאר את סדר העבודה המחייב ליצירת או לעדכון דף נחיתה. מטרתו לשמור על קשר ברור בין קהל היעד, הבעיה, הפתרון והעיצוב.

## מקורות אמת

| החלטה | מקור אמת |
| --- | --- |
| כללי כתיבה והבטחות | `docs/writing-style.md` |
| החלטות עסקיות, קהל ומסר | בריף המשפחה ב־`docs/landing-page-families/` |
| שפה חזותית ורכיבי ממשק | ספר העיצוב ב־`docs/design-systems/` |
| הגדרות משפחה מובְנות | `src/content/landing-page-families.ts` |
| תוכן, הצעה ופרטי עמוד מסוים | קובץ ה־MDX ב־`src/content/landing-pages/` |

במקרה של סתירה, לא משנים את העמוד כדי לעקוף אותה. מעדכנים קודם את מקור ההחלטה המתאים, ולאחר אישור מעדכנים את הקוד או התוכן.

## סדר העבודה

1. **בריף** — מגדירים קהל, בעיה, טריגר רכישה, פתרון, גבולות והמרה.
2. **ספר עיצוב** — מתרגמים את הבריף לשפה חזותית, מבנה עמוד, רכיבים וכללי תוכן.
3. **אישור** — מאשרים את הבריף ואת ספר העיצוב לפני שינוי עמוד קיים או קוד פעיל.
4. **תוכנית יישום** — ממפים את הטוקנים, הרכיבים, הנכסים ושדות התוכן שיידרשו.
5. **פיתוח וכתיבה** — מיישמים לפי התוכנית, תוך שמירה על מקורות האמת.
6. **בדיקות** — מריצים בדיקות תוכן ו־build, ובודקים ידנית RTL, מובייל, נגישות והמרה.

## מחקר וחומרי ייחוס

חומרי ייחוס משמשים להבנת המוצר, השוק או השפה הקיימת. הם אינם הוראת כתיבה, אינם מקור להבטחות, ואינם מיועדים להעתקה.

צילום המסך של דף RavPage של "אנגלית מעצימה לי עם מלי" מופה עבור משפחת `reading-foundations` בלבד. ממנו נשמרו עקרונות כלליים: דף מובייל ארוך, צבעוניות כחולה־צהובה־אדומה, כרטיסי לימוד חזותיים, הצגת היקף הקורס, אזור התאמה ועדויות. לא נשמרו נוסחים, הבטחות תוצאה או טענות מקצועיות שלא אושרו בפרויקט.

## בדיקת מוכנות לפני יישום

לפני תחילת פיתוח ודאו:

- לבריף ולספר העיצוב יש סטטוס מאושר.
- טווח הגיל, המוצר, מסלול הרכישה והנכסים זמינים וברורים.
- מחיר, מבצע ותוקף קיימים רק אם אושרו עסקית.
- לכל עדות יש אישור שימוש, שם או אופן אנונימיזציה מאושרים.
- אין הבטחות מוחלטות, טענות אבחוניות או טענות תוצאה שאינן מבוססות.

## בדיקות מסירה

- `npm run content:check` עובר.
- `npm run build` עובר.
- העמוד נבדק במובייל ובמסך רחב, ב־RTL ובמקלדת.
- הצבעים, הטיפוגרפיה והתמונות עומדים בספר העיצוב.
- המסך הראשון מבהיר למי הדף מיועד, מהו הקושי ומהי הפעולה הבאה.
