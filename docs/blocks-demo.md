# דף הדגמה מקומי לבלוקים

## סדר עבודה ואישורים

העיצוב העדכני ב־Google Stitch אושר בשיחה במילים ״טוב בוא נמשיך״ אחרי הצגת הסט המתוקן. הוא ממומש כעת לבדיקה מקומית. אחרי אישור האלמנטים כאן עוברים לתוכן הדף. הבריף וקישורי המסכים מרוכזים ב־[הרקעים וסבבי העיצוב](design-review/rich-backgrounds.md).

מריצים `npm run dev` ופותחים `/blocks-demo`. הדף זמין רק בפיתוח; בבניית production הוא מחזיר 404.

הקטלוג ב־`src/pages/blocks-demo.astro` כולל מסגרות נפרדות: סוגי הבלוקים ורקעים מפורשים למקטעי הטקסט, שמונה משפחות רקע, טיפוגרפיה, שלוש וריאציות קיקר, מצבי כפתורים ראשיים/משניים/הפוכים וחמשת סגנונות ה־CTA שנבחרים ב־EmDash, כרטיסים רגילים וממוספרים, תג מספר, תמונה, פרופיל, גלריה, שאלה ותשובה, שדות מושבתים, רשימה ומקום לעדות מאושרת. האיורים המקומיים נמצאים ב־`public/images/blocks-demo/`.

`/blocks-demo/story` מציג דף דוגמה רציף, מאותם רכיבים ועם תוכן גנרי: קושי → הסבר ותהליך → היכרות → דוגמאות → מקום לעדות → התאמה → שאלות → הצעה → סיום. הרקעים והקיקרים עוקבים אחרי הסיפור שאושר. התוכן האמיתי והמדיה המפורסמת נשארים ב־EmDash.

`src/styles/presentation.css` מממש עיצוב משותף בתוך `body.landing-page`. רכיב `Section` מקבל `surface`, שממופה מבחירת `background` במודל. `Kicker` ו־`FaqList` משותפים לדפים ולדוגמאות.

זהו תוכן המחשה בקוד בלבד, ללא רשומה או סכמה ב־EmDash. כל קישורי הפעולה פנימיים. קישורי המקור פותחים את מציג הקוד המקומי `/blocks-demo/source`, הזמין רק בפיתוח ומוגבל לרכיבי התצוגה ולעותקי הסכמות. `OfferBlock` מקבל תוכן וקישור פעולה מאומתים; אין בו מצב טופס או טקסט ברירת מחדל.

כל דוגמה מוצגת במסגרת עם שם סוג הבלוק, השדות המוצגים וקישורים לסכמת האובייקט, לרכיב התצוגה ולמיפוי ב־renderer. מסגרות מקווקוות מסמנות את האלמנטים בתוך כל דוגמה. כרטיסים, גלריה, פרופיל ושאלות נפוצות הם שדות של `landing_content_section`; כותרת האתר והפעולה הניידת הם רכיבי ממשק ולא סוגי בלוקים.

`src/data/blocks-demo/*.json` מכיל עותקי סכמה לקריאה בלבד שאומתו ב־13.10.2026 באמצעות EmDash MCP. הם אינם מגדירים את הסכמה הפעילה ואינם משמשים לשינוי CMS. יש לאמת ולרענן אותם דרך MCP כשמודל התוכן משתנה.

## בדיקות המימוש — 11.10.2026

בעל האתר אישר להמשיך אחרי הצגת המימוש המקומי (״okay let's continue״). שלב אישור האלמנטים הושלם. נוצרה טיוטת תוכן ב־EmDash, גרסה 6, ותצוגה מקומית ב־`/blocks-demo/reading`. זוהי תצוגה של עותק מסונן שנקרא דרך MCP; לא מקור תוכן עצמאי. מדיה נטענת מהאתר שבו EmDash מנהל אותה, קישורי הפעולה פנימיים והטופס מושבת. פרטי אינטגרציה לא הועתקו לתצוגה.

- הקטלוג כולל 51 מסגרות וקישורי תוכן עניינים ליעדים קיימים. מציג המקור מחזיר 200 עבור תוכן ההמחשה, הסגנונות, הרכיבים החדשים ועותק הסכמה.
- נבדקו מידות ב־320px, 390px ו־1440px. לא נמצאה גלילה אופקית; מסגרת הקריאה בדף הרציף 512px במסך רחב. נבדקו ערכי הרקע בפועל לכל שמונת הגוונים וגודלי טקסט גוף/כרטיס/כותרת.
- בדף הרציף 10 מקטעים וששת קיקרי המעבר המתוכננים. שאלה נפתחה בלחיצה. ארבע התמונות נטענו אחרי גלילה. כל שדות הקלט מושבתים ואין סקריפט Ravpage או מעקב בדפי ההדגמה.
- נתיבי הקטלוג, הסיפור ומציג המקור מחזירים 200 בפיתוח ו־404 בריצה מקומית של בניית production.
- `npm run check` עבר. כלי צילום המסך בדפדפן החזיר timeout; בדיקות הדפדפן התבססו על DOM, סגנונות מחושבים, מידות ופעולות ממשק. בדיקת המראה ואישורו בידי בעל האתר עדיין נדרשים.

## מודל ותצוגה — 13.10.2026

עותקי הסכמות והטיוטה רועננו דרך EmDash MCP לגרסאות 2. העיצוב משותף לתצוגה מקדימה ולדפים רגילים. רשימות נקבעות ב־`paragraph_format`; רקע נקבע ב־`background`; גלריה אינה משנה אותו. ההצעה מציגה קישור תשלום ולא טופס. ראו `docs/landing-pages/reading/README.md` לחוזה האימות ולתאימות גרסאות.
